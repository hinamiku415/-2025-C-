# 树莓派 4B 与 STM32 发射主控串口通信协议规范

## 1. 物理层与串口配置
- **波特率 (Baudrate)**: 115200 bps
- **数据位 (Data bits)**: 8 bits
- **停止位 (Stop bits)**: 1 bit
- **校验位 (Parity)**: None
- **硬件引脚**:
  - STM32 (USART2 / USART1) TX -> 树莓派 RX (GPIO15 / Pin 10)
  - STM32 RX <- 树莓派 TX (GPIO14 / Pin 8)
  - GND 务必共地 (Common Ground)

---

## 2. 帧格式与校验机制

为了防止电磁干扰、电机启动噪声以及杜邦线抖动导致的误触发，通信协议支持 **带 XOR 校验的防干扰帧格式**（兼容普通明文换行格式）：

### 2.1 增强防干扰格式（推荐）
```text
$<Payload>*<Checksum>\r\n
```
- 起始符：`$` (ASCII 0x24)
- 负载段：任意 ASCII 命令或数据字符串
- 分隔符：`*` (ASCII 0x2A)
- 校验和：2 字节十六进制大写，计算方法为 `<Payload>` 内所有字符字节的异或和（XOR Checksum）
- 终止符：`\r\n` (CRLF)

### 2.2 基础文本格式
```text
<Payload>\n
```

## 3. 指令集定义

### 3.1 主控台 (STM32) -> 树莓派 (Pi 4B)
| 命令字符串 | 说明 |
| :--- | :--- |
| `MODE:1` | 启动模式 1：单板测量（A4靶板识别与中心测距） |
| `MODE:2` | 启动模式 2：双几何图形识别与边长/直径计算 |
| `MODE:3` | 启动模式 3：重叠重度遮挡正方形识别与数字解算 (2, 8, 4) |
| `MODE:4` | 启动模式 4：动态跟踪与连续测距（小车直线运动） |
| `MODE:5` | 启动模式 5：大角度斜向/折线运动轨迹测量 |
| `MODE:6` | 启动模式 6：变频调速动态目标物实时功耗与轨迹同步测试 |
| `STOP`   | 停止当前视觉处理任务，返回待机状态 |
| `CALIB`  | 触发摄像头标定与靶面基准对齐模式 |

### 3.2 树莓派 (Pi 4B) -> 主控台 (STM32)
| 数据格式 | 示例 | 含义说明 |
| :--- | :--- | :--- |
| `D:<distance>` | `D:152.40` | 发送实时中心测距结果（单位：cm） |
| `D:<dist>,shape:<type>,x:<size>` | `D:150.00,shape:square,x:10.05` | 几何图形类型 (`square`/`circle`) 及边长/直径 |
| `D:<dist>,N:<num>,x:<side>` | `D:148.20,N:8,x:9.98` | 模式3单方块解析：数字标签 + 边长（cm） |
| `STATUS:mode=<m>,status=<s>` | `STATUS:mode=3,status=2` | 模式执行状态（0:就绪, 1:测量中, 2:完成, 3:超时/错误） |
| `ERROR:<msg>` | `ERROR:TARGET_LOST` | 视觉异常报警（如丢失靶标、光照不足） |

## 4. 容错与重试机制
1. **零延时抓帧防抖**：树莓派端采用独立多线程后台持续 `grab()` 抛弃陈旧帧，STM32 下发指令后在 30ms 内即可获取物理世界最新图像。
2. **校验过滤**：收到带 `$` 格式时，树莓派或 STM32 会实时校验 XOR 结果；若有噪点导致校验失败，整帧直接丢弃，不执行任何误动作。
3. **超时保护**：STM32 设定 10s 总限时状态机，若未在赛题规定时间内收到测量完成包，自动结算并报警。
