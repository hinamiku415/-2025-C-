# 陶晶驰 (TJC) HMI 串口屏固件与工程源文件

本目录包含测量台发射主控连接的陶晶驰触摸串口屏工程与烧录固件。

---

## 1. 文件说明

| 文件名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `TJC_HMI_Firmware.tft` | 编译镜像 (9.2MB) | **直接烧录固件**。复制到 TF/SD 卡根目录即可一键刷入串口屏。 |
| `TJC_HMI_Project.HMI` | 工程源码 (16.1MB) | **上位机编辑源文件**。使用官方「USART HMI」软件打开，可二次修改 UI 布局、文本控件、按键事件和字体。 |

---

## 2. 硬件接线规范

串口屏通过 **USART1** 与 STM32F103 主控通信：

| 串口屏引脚 | STM32 引脚 | 信号说明 | 备注 |
| :--- | :--- | :--- | :--- |
| **TX** | **PA10** (USART1_RX) | 屏幕发送 -> STM32 接收 | 触摸按钮事件、模式切换指令 |
| **RX** | **PA9** (USART1_TX) | STM32 发送 -> 屏幕接收 | 电流功耗刷新、测距结果、数字显示 |
| **+5V** | **+5V** | 供电正极 | 建议独立 5V 1A+ 供电防白屏重启 |
| **GND** | **GND** | 信号共地 | 必须与 STM32 共地 |

- **通信波特率**：`9600 bps`（8-N-1）

## 3. 固件刷机方法 (TF / SD 卡一键烧录)

1. **准备 SD 卡**：准备一张容量 $\le 32\text{GB}$ 的 Micro SD (TF) 卡，格式化为 **FAT32**（分配单元大小推荐 `4096 字节`）。
2. **复制固件**：将 `TJC_HMI_Firmware.tft` 复制到 SD 卡**根目录**（确保根目录下只有这一个 `.tft` 文件）。
3. **断电插卡**：确保串口屏断电，将 SD 卡插入串口屏背面的卡槽。
4. **上电烧录**：给串口屏接通 5V 电源，屏幕将自动进入刷机界面，显示进度百分比。
5. **完成拔卡**：当屏幕显示 `Update Successed!` 时，**务必先断开电源**，再拔出 SD 卡，重新上电即可正常进入电赛主测量界面。

## 4. 二次开发指南
若需修改界面文字、添加按键或更换字库：
1. 下载并安装官方 **USART HMI** 软件；
2. 打开 `TJC_HMI_Project.HMI` 即可查看全部页面组件、页面变量与字库；
3. 编辑完成后点击顶部菜单 **「输出」->「输出TFT文件」** 即可重新生成 `.tft` 烧录镜像。
