## 发送流程

```mermaid
sequenceDiagram
    participant App as 应用层
    participant Core as 中间层
    participant Port as 底层
    participant Screen as 串口屏

    App->>Core: TJC_HMI_SetText("D", "120.5cm")
    Core->>Core: 拼接指令 "D.txt=\"120.5cm\""
    Core->>Port: TJC_Port_SendByte('D')
    Core->>Port: TJC_Port_SendByte('.')
    Core->>Port: TJC_Port_SendByte('t')
    Core->>Port: ...
    Core->>Port: TJC_Port_SendByte(0xFF)
    Core->>Port: TJC_Port_SendByte(0xFF)
    Core->>Port: TJC_Port_SendByte(0xFF)
    Port->>Screen: USART_SendData() → TX 引脚
    Screen->>Screen: 显示 "120.5cm"
```

## 接收流程

```mermaid
sequenceDiagram
    participant Screen as 串口屏
    participant Port as 底层
    participant Core as 中间层
    participant App as 应用层

    Screen->>Port: 按钮按下 → RX 引脚
    Port->>Port: USART1_IRQHandler()
    Port->>Port: 读取字节 0xA5
    Port->>Core: TJC_HMI_RxByte(0xA5)
    Core->>Core: 状态机：收到帧头
    Port->>Core: TJC_HMI_RxByte(0x01)
    Core->>Core: 状态机：存入 ID
    Port->>Core: TJC_HMI_RxByte(0x31)
    Core->>Core: 状态机：存入数据
    Port->>Core: TJC_HMI_RxByte(0x5A)
    Core->>Core: 状态机：收到帧尾，解析
    Core->>App: 回调：TJC_EVENT_DATA, id=1, value=1
    App->>App: 判断 ID：1 = 距离
    App->>App: target_D = 1
```

## 分层职责

| 层 | 文件 | 职责 |
|----|------|------|
| 应用层 | 你的代码 | 定义 ID 含义、处理业务逻辑 |
| 中间层 | tjc_hmi.c | 协议解析、生成事件、控件操作 |
| 底层 | tjc_hmi_port.c | 串口初始化、收发字节、硬件操作 |

## 两个回调函数

| 回调 | 方向 | 作用 |
|------|------|------|
| `TJC_HMI_RxByte()` | 底层 → 中间层 | 喂入接收到的字节 |
| `TJC_HMI_Callback_t` | 中间层 → 应用层 | 通知事件（按钮/数据） |
