# TargetCar_STM32: 目标小车运动控制端

## 1. 模块简介
本工程为“基于单目视觉的目标物测量装置”中的运动目标小车固件，主控芯片采用 **STM32F103C8T6**。小车背负 A4 尺寸特征靶板（包含数字正方形、几何图形），在地面预设黑色导引线上做直线循迹、定距制动及大角度轨迹运动。

## 2. 硬件拓扑与外设配置
- **电机与驱动**：TB6612FNG 双路 H 桥驱动芯片，驱动 2 只 MG513X 直流减速电机。
- **测速反馈**：MG513X 自带 AB 相增量式霍尔编码器，STM32 定时器配置为编码器模式（4倍频计数）。
- **循迹寻线**：8 路高精度数字红外灰度传感器阵列（PE7 数据脚 / PE8 时钟脚），采用加权平均算法输出偏差量。
- **无线通信**：NRF24L01 2.4GHz 射频模块，接收来自测量台的“定速启动”、“定距停止”、“加减速”等遥控指令。
- **本地调试**：0.96寸 I2C OLED 显示屏，实时监控车速、目标距离及 PID 积分量。

## 3. 控制算法架构
1. **循迹转向环 (PD)**：
   - 8 路灰度传感器采用加权评分机制（权重分布：`[-8, -6, -4, -2, +2, +4, +6, +8]`）。
   - 计算得到当前轨迹中心偏移量，通过比例微分控制器动态调节左右轮差速，保证小车在大曲率弯道和直线段均能平滑循迹。
2. **运动速度环 (PI)**：
   - 定周期（10ms）读取编码器增量计算实际线速度，与目标速度比对后输出 PWM 占空比。
3. **位置停靠环 (串级 PID)**：
   - 目标小车接收到指定运行距离指令（如 1.5m / 2.0m）后，闭环积分编码器脉冲数，平滑减速并在赛题允许误差范围（±1cm）内精准刹停。

## 4. 目录结构
```text
├── Hardware/        # TB6612电机驱动、编码器、NRF24L01、OLED驱动
├── Track/           # 8路红外灰度循迹算法与权重解算
├── User/            # main.c 主状态机与中断调度
├── Start/ & Library/# STM32F10x 标准固件库与启动代码
├── System/          # 延时与系统滴答定时器
└── Project.uvprojx  # Keil MDK 5 主工程文件
```

## 5. 编译与烧录
- **开发工具**：Keil MDK 5 (ARM Compiler V5 / V6)
- **调试器**：ST-Link V2 / DAP-Link / J-Link
- 打开 `Project.uvprojx`，点击 `Build` (F7)，通过 SWD 接口直接烧录即可。
